# ADR 0003：采用 C#、.NET LTS 与 WPF

Status: Accepted

建议使用 C#、当前受支持的 .NET LTS 和 WPF。该组合能直接使用 COM/UIA 与 Win32 互操作，适合把异步、取消、不可变状态和测试组织成可维护的深模块；WPF 对 Windows 专用的小型托盘、设置和无激活提示层足够成熟。相比 C++，它减少内存与生命周期维护成本；相比 Rust，Windows UIA/COM 和桌面 UI 的工程阻力更低；相比 AHK/aardio，更容易建立状态机、Trace 回放和长期自动测试。代价是运行时与常驻内存更大，需在探针阶段用性能预算验证。目标框架版本在阶段 0 按微软支持策略锁定，不在文档中长期写死补丁版本。
