# ADR 0002：V1 不使用全局键盘 Hook

Status: Accepted

完整取词工具需要全局输入手势状态机，但 InputCue 不读取选中文本，也不必理解所有键盘选区手势。V1 采用焦点/前台事件、UIA 语义和仅在活跃输入上下文中的自适应采样；必要时在鼠标交互期间重新评估 Selection。这样降低游戏和安全软件冲突、权限差异、性能与隐私风险。

提示显示期间，InputCue 使用 Windows Raw Input 判断是否发生了编辑类按键活动，以实现“开始输入后隐藏”。该监视器不使用全局键盘 Hook，不保留或传播虚拟键码，不还原输入文本，也不把按键活动写入诊断记录；它只向显示状态机发送一次匿名活动信号。只有当脱敏 Trace 证明某个关键不变量无法用现有事件建立时，才另写 ADR 重新评估 Hook，不能以单个应用兼容为由直接加入。
