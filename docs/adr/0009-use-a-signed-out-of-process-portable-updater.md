# 0009：使用签名清单和独立进程更新便携版

## 状态

已接受

## 决策

InputCue 以包含 `InputCue.exe`、`InputCue.Updater.exe` 和 `portable.flag` 的绿色便携 ZIP 发布。便携模式把设置和更新状态写入同目录的 `data`，更新包不得包含或替换该目录。

主程序负责按 24 小时门限获取更新清单、校验嵌入公钥对应的 ECDSA 签名、比较版本、下载 ZIP 并验证长度和 SHA-256。发现新版后，无论检查来自自动调度还是界面按钮，都复制并启动临时目录中的独立更新器，然后退出。

独立更新器等待主进程结束，在安装目录同级安全解压和备份，只替换新包明确提供的程序文件；失败时回滚，成功后重启主程序。客户端不使用安装服务、计划任务或短周期轮询。

## 影响

启动时会判断一次是否到期；自动网络检查最多每 24 小时一次，连续运行时只保留一个可取消的延时任务。手动检查立即执行并刷新同一检查时间。

更新清单签名保证发布来源和内容完整性，但不能替代 Authenticode，也不能消除 Windows SmartScreen 对未签名程序的提示。启用开机启动仍会按用户选择写入当前用户 Run 注册表项。
