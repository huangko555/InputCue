# ADR 0010：自定义提示图标以用户文件为唯一真相源

Status: Accepted

「自定义」是第四套提示样式：四个输入状态可分别指定一张 PNG，渲染时整块替换内置字形与卡片。图片不进入 settings.json，`data/icons/` 下四个标准文件名（chinese.png、ime-english.png、us-english.png、caps-lock.png）就是唯一真相源：文件存在且有效即生效，缺失或无效回退内置描边样式。这与绿色便携定位一致——`data/` 从不进入发布 ZIP、永不被更新器替换；GUI 选择图片只是复制成标准名，手动放文件与 GUI 操作共享同一存储层，不会出现第二份真相。

格式上仅接受 PNG：WPF 原生解码、透明支持好、防呆面最小；矢量格式需要第三方解析库，保真与容错成本高，留待确有需求再引入。防呆策略是"不符合标准直接不生效并给出原因"：目录扫描只做文件级校验（可解析 PNG 头、≤10 MB、≤4096×4096），解码失败在加载层静默回退，渲染热路径只消费已冻结的位图，绝不因用户文件白屏或崩溃。生效模型沿用设置页的实时约定：选择即校验、复制、重扫、预览即见；窗口激活时以变更检测做一次廉价重扫，兼顾直接改文件的场景。窗口与设置预览的视觉决策收敛在共享的 IndicatorVisualRenderer 中，避免"预览与实际不一致"的漂移。
